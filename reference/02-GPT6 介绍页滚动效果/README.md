# 02-GPT6 介绍页滚动效果 reference effect

Open `index.html` from a local web server or the casebook. The primary example is the Chinese title “推出智能界面”: “推出” stays fixed while a custom pointer approaches “智能界面”, grips it, drags it to the shared baseline, and releases. Its pose follows scroll position, stays partial during a pause, and retraces on upward scrolling. Four additional moving phrases and three per-line blue selections illustrate the broader interaction. Resizing reconstructs highlight lines. Reduced-motion preference removes decorative displacement and the pointer.

The title stages are an independently calibrated approximation of observed positions, not the original page's algorithm. This study uses original copy, system fonts, and abstract media, so it is not an entire-page pixel reproduction. It is intentionally separate from `case/02-GPT6 介绍页滚动效果/starter`, which should be copied alone to candidates.
