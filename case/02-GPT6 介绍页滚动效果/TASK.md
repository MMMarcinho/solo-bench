# 02-GPT6 介绍页滚动效果

请从 `starter/` 的最小脚手架完成 [OpenAI 中文介绍页](https://openai.com/zh-Hans-CN/index/gpt-6-for-everyone/) 的文章式 UI 与关键随滚动动效。可用原创演示文案、系统字体和简化的辅助媒体；不要复制原站整篇正文、视频或专有字体。需要完成导航、标题与正文的视觉层级、阅读列、留白、手机布局，以及可用的锚点链接。静态 HTML 与现有 CSS 只是起点，不是完成稿。

**核心标题**是同一行的“推出”＋“智能界面”。“推出”保持在正常布局位置，四字短语以自身中心为旋转原点，从约向右 110px、向下 24px、旋转 5° 的位置，被指针带动回到“推出”后面；终点两段文字直接相接，不留人为的大空隙。标题约 28.5px 字号、37.7px 行高。标题下方的正文不随它变换。指针约 24px，黑色、粗白描边，hotspot 约为 (4,4)：先从右下靠近而文字不动，接触时缩小到约 .86，随后牵引短语先轻微下沉再上升转正；文字归位以后才放开、恢复原大小并向右上退出淡出。握住时指针应贴近短语末字，朝向顺着运动方向变化。不要把指针只放在蓝色正文高亮旁边。

标题姿态由**未变换的标题锚点 top ÷ 视口高度**驱动。1180 × 757 视口的参考观察：锚点约在 .94H 时文字仍为 110px／24px／5°、指针已经靠近；在 .82H 时文字约为 70px／30px／3.3°、指针握住；在 .57H 时文字归位，指针尚未离开；约 .45H 时指针退出。可以用自己的插值与平滑方法实现近似，不要求复制原站内部算法。停在任一中间位置超过 10 秒应保持该姿态，不得进入视口后自动播完；继续下滚推进，上滚按同一路径撤回，同一锚点位置的文字姿态不应依赖方向。

其余三个 `data-effect="highlight"` 段落需要在真实换行后的每一行由左至右增长浅蓝色高亮，黑色指针跟随蓝色前缘。其他正文动效可以配合文章，但不能替代上述标题。所有强调效果在暂停时停住、上滚时撤销、resize 后重新对应换行。请保留 starter 的 `data-title-anchor`、`data-title-fixed`、`data-title-phrase`、`data-title-pointer`、`data-static-body` 和 `data-effect`／`data-effect-id` 观察锚点；它们仅定位实际元素，不能以自报进度或状态取代可见行为。

在 1180 × 757 桌面和 390 × 844 手机视口检查页面与动效。尊重 `prefers-reduced-motion`：去掉装饰性文字位移和移动指针，保持标题、正文与强调内容清楚可读。无需后端、模型 API、登录或构建工具。只交付编辑后的候选目录；`reference/` 与 `grader/` 不属于候选输入。
